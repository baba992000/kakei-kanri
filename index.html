機能選択 (ON/OFF切り替え)

ライフステージに合わせて、必要な機能だけを選択して使用できます。

アルバイト収入 アルバイトや副業などの収入カテゴリを追加します。
サブスク管理 月額サービスを「サブスク」として登録し、毎月の固定費を管理。
家族共有機能 登録者（自分/パートナー）を設定し、個別の集計や絞り込みを行います。
🏦 共同口座連携 パートナーと共有する生活費口座を連携。残高・拠出状況・精算バランスを一括管理。銀行明細同期＆CSV取込対応。
固定費分析 支出を固定費と変動費に分類し、割合をグラフィカルに分析します。
年金・長期積立管理 将来用の積立を管理し、資産の状況をより詳細に把握します。

💡 音声入力の話し方ガイド

「音声で入力」ボタンを押した後、以下のように自然に話しかけてみてください。

  • 「今日 食費 850円 ランチ」 → 日付:今日 / 支出 / 食費 / 850円 / メモ:ランチ
  • 「昨日 交通費 420円 電車代」 → 日付:昨日 / 支出 / 交通費 / 420円 / メモ:電車代
  • 「スタバでカフェラテ 620円」 → 支出 / 食費 / 620円 / メモ:スタバでカフェラテ
  • 「給料 25万円」 → 収入 / 給与 / 250,000円
  • 「普通預金に3万円 貯金」 → 貯金 / 普通預金 / 30,000円
